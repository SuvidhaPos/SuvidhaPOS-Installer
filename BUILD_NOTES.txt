BUILD NOTES - 2.1.2

Build configuration alignment:
- build.ps1 and .github/workflows/build.yml now use the same .NET 8 win-x64 build/publish settings.
- PublishSingleFile=false and PublishTrimmed=false are enforced in both paths.
- The complete self-contained publish folder is passed to Inno Setup.
- The local PowerShell build validates the EXE, DLL and Suvidha POS logo assets before packaging.
- The local script accepts the standard Inno Setup 6 install path under either Program Files (x86) or Program Files.

Windows startup/resume:
- The installer saves progress to %ProgramData%\SuvidhaPOS\Installer\resume.json.
- A Scheduled Task named "SuvidhaPOS Installer Resume" is created while setup is incomplete.
- The task launches the installer at interactive logon after Windows restart/power recovery.
- The task is removed when the Finish step marks setup complete.

UI/assets:
- Premium 7-step WinForms UI is retained.
- SuvidhaPOS logo/icon and wizard assets are retained.
- The application manifest keeps PerMonitorV2 DPI awareness for responsive rendering.
