BUILD NOTES - 2.2.0

UI:
- Rebuilt the responsive WinForms layout to avoid fixed-position overlap.
- DPI scaling is configured through the .NET project (PerMonitorV2), not manifest dpi settings.
- Narrow windows use a compact sidebar instead of squeezing navigation text.
- Footer, welcome, component, download, install and setup layouts resize with the window.
- Custom cards are double-buffered to reduce repaint/flicker artifacts.

Downloads:
- Exact software/download directory: D:\Suvidha Pos\Software
- Installer application directory: C:\Suvidha Soft Installer
- All downloaded installers are saved directly in that directory.
- No software subfolders are created.
- Local file detection is flat (TopDirectoryOnly) for MSI, VC++ and backup files.

Build:
- Self-contained win-x64 .NET 8 publish.
- PublishSingleFile=false.
- Full publish directory is packaged by Inno Setup.
- GitHub Actions performs the authoritative Windows build.
