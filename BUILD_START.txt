SuvidhaPOS Installer V2.3 - Clean Build Start

GitHub:
1. Push this complete folder to the repository's main branch.
2. Open GitHub -> Actions.
3. Select "Build Suvidha POS Installer".
4. If no automatic run appears, select "Run workflow" -> branch main -> "Run workflow".
5. Wait for the Windows job to finish.
6. Download artifact "SuvidhaPos-Installer-Windows-x64".
7. The final file is SuvidhaPOS-Installer-Setup.exe.

If Actions shows no workflow:
- Confirm GitHub Actions is enabled in repository Settings -> Actions.
- Confirm this file exists exactly at .github/workflows/build.yml on main.
- Confirm the repository's default branch is main.

Local Windows build:
- Requires .NET 8 SDK and Inno Setup 6.
- Run PowerShell from the repository root:
  .\build.ps1
- Final installer:
  .\release\SuvidhaPOS-Installer-Setup.exe
