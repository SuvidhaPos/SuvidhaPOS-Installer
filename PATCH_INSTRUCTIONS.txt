Suvidha POS Installer - UI Polish Patch
========================================

Problem confirmed from the supplied screenshot:
- A horizontal scrollbar is appearing on the Download page.
- The progress cards are wider than the available content area.
- Because of that horizontal overflow, the left side of text is clipped/shifted.
- Fixed child widths are being calculated from `content.ClientSize.Width`
  instead of the actual `pageBody`/FlowLayoutPanel width.

Patch included:
1. Installer/UiPolish.cs
   - disables horizontal overflow
   - recalculates card widths from the actual page width
   - keeps progress bars responsive
   - prevents long component names from overlapping
   - adds subtle 3D/pressed/hover behavior to normal buttons
   - reapplies after every page rebuild and window resize

2. Installer/Program.cs
   - starts the UI polish layer immediately after MainForm creation.

How to apply:
- Copy UiPolish.cs into Installer/
- Replace Installer/Program.cs with the included Program.cs
- Keep the existing MainForm.cs and all existing installer/download/install logic unchanged.
- Build normally with the existing build.ps1.

Expected result:
- No horizontal scrollbar on Download/Install pages.
- SQL Server 2019, SSMS, Crystal Reports, VC++ and Suvidha POS cards stay inside the window.
- Text remains readable from 800x600 through large resolutions.
- Footer buttons remain aligned to the right.
- Existing native Microsoft installers continue to open normally.
